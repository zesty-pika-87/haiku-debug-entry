A Node program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape — to `/output/entry.txt`. A stack trace at midnight, a bug hiding where all the tests pass, and the last line turns the poem: it was a typo.

## Run it

```sh
node main.ts
```
